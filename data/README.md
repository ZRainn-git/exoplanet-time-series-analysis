# Data

This project uses the **Kepler Labelled Time Series Data** dataset derived from observations by NASA's Kepler Space Telescope.

The original dataset files are not included in this repository due to their size.

To reproduce the analysis, download:

- `exoTrain.csv`
- `exoTest.csv`

from the Kepler Labelled Time Series Data dataset on Kaggle and place them in this directory.

The light curves contain sequential stellar flux measurements sampled at approximately 30-minute intervals.
